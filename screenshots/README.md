# Screenshots

Pasta reservada para prints do produto (landing, login, painel, proposta, PDF).

Ainda não há imagens versionadas. Quando for publicar o template ou um clone:

1. Rode `npm run dev` com a seed (`demo@comercial.local` / `demo1234`).
2. Capture em desktop (1440px) e, se possível, um recorte mobile.
3. Exporte PNG ou WebP leves.
4. Nomes sugeridos:
   - `01-landing.png`
   - `02-login.png`
   - `03-dashboard.png`
   - `04-proposta.png`
   - `05-pdf.png`
5. Referencie no README do produto.

Não commite dados reais de clientes.
